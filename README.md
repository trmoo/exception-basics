# 🥤 부숴봐! 자판기 (교재판) — 파이썬 예외 처리

> © 2026 티쳐무 · 모든 권리 보유 — 학교 수업 목적으로만 이용해 주세요. ([LICENSE](LICENSE))

교재 12장 A 「예외 처리」를 **카드 넘기기 게임**으로 배우는 앱입니다.
자판기 뒤에서 파이썬 코드가 진짜로 돌고, 학생은 이상한 값을 넣어 자판기를 **고장 내며 예외 5종을 모은 뒤**,
`try`·`except` 로 **방어막을 짜서 같은 공격을 다시 막습니다.**
선생님은 **교사 대시보드**에서 반 전체의 진행과 「가장 많이 막힌 곳」을 실시간으로 봅니다.

- 대상: 고등학교 「정보」·「프로그래밍」 파이썬 — 예외 처리
- 한 화면에 한 가지만 — 화면이 1280×720 카드 한 장이라 **교실 TV·노트북 어디서나 스크롤이 없습니다**
- 파이썬 설치 없이 브라우저에서 진짜로 실행됩니다
- 학생은 맨 처음 **학번 · 이름 · 비밀번호**로 로그인하고 자리 번호를 고릅니다. 선생님 시트에만 남고, 발표 화면에는 이름을 가립니다(홍*동).
  비밀번호는 알아볼 수 없게(솔트 + SHA-256 해시) 숨긴 `계정(비밀번호)` 시트에만 저장되어 선생님도 볼 수 없습니다

## 카드 차례 (= 교재 절 차례)

| 단원 | 카드 |
|---|---|
| 시작 | ① 로그인 — 학번을 적으면 처음 온 학생은 이름·비밀번호를 정하고, 다시 온 학생은 비밀번호만 → ② 자리 번호 고르기 (새로고침해도 「이어서 하기」, 2차시에 자리를 옮겨도 기록이 이어짐) |
| 1. 예외란 | 예외가 나면 멈춘다 → 🎰 **부숴봐!** (자판기 고장 내기, 막히면 💡 힌트를 하나씩) → 📖 **예외 도감** 5종 |
| 2. try–except | 교재 예제 실행 → 🛡️ 미션 1 |
| 3. 여러 except | 교재 예제 두 개 실행 → 🛡️ 미션 2 |
| 4. else·finally | 숫자 / 글자를 넣어 실행 → 🛡️ 미션 3 |
| 5. 보스전 | 👾 공격 10가지 + 정상 손님 3명 (별 셋) → ⚠️ `except:` 만 쓰면 안 되는 까닭 |
| 6. 확인 문제 | 4문항 → 🏁 오늘의 결과 (「오늘 배운 것」은 선생님과 함께 학생이 직접 적는다 — 💡 는 실마리 낱말만) |

교재 표의 예외 6종 가운데 **FileNotFoundError 는 뺐습니다** — 학생들이 아직 파일 입출력을 배우기 전이라서입니다.

← → 키나 아래쪽 단추로 넘깁니다. 오른쪽 위 **🧹 기록 초기화** 를 누르면 이 기기의 활동 기록(도감·힌트·미션·확인 문제·코드)을 모두 지우고 처음부터 시작합니다(선생님께 이미 보낸 기록은 남습니다). 아래 단원 이름을 누르면 그 단원으로 바로 갑니다.

## 교사 대시보드

웹 앱 주소 끝에 `?page=teacher` 를 붙여 열고 교사 암호를 넣습니다.

- **🆕 새 수업** — 반 이름(예: 「2-3 반」)과 **이번 시간에 열 카드(1차시 · 2차시 · 전체)** 를 정하면 학생 시작 카드에 그 수업이 뜹니다.
- **🗂 범위** — 수업 중에도 1차시 ↔ 2차시를 바꿀 수 있습니다. 학생 화면은 카드를 넘길 때(15초 안팎) 바뀝니다.
  **같은 반의 2차시는 새 수업을 만들지 말고** 📚 수업에서 그 반을 고른 뒤 🗂 → 「▶ 이 수업 이어서 하기」 → 2차시. 그래야 학생 기록이 이어집니다.
  - 1차시: 예외란(부숴봐!·도감) · try–except(미션 1) · 여러 except(미션 2) · ⭐ 심화(실행 오류와 논리 오류 · 🔍 논리 오류 사냥 — 빨리 끝낸 학생용)
  - 2차시: else·finally(미션 3) · 보스전 · 남용 주의 · 확인 문제
- **📺 발표** (TV 에 띄워 함께 봄) — 우리 반이 찾은 예외 5장과 첫 발견 번호 · 순위 · 방금 소식.
  새 「첫 발견」 이 나오면 화면에 크게 뜹니다.
- **🔍 선생님** — 학생마다 카드·미션·확인 문제 진행 · 미션별 통과 수 · **가장 많이 막힌 곳** · 확인 문제 정답률.
- **📚 수업** — 지난 수업을 골라 다시 볼 수 있습니다.

5초마다 새로 읽습니다. 학생 기기는 카드를 찾거나 미션을 통과할 때만 짧게 보내므로,
한 반이 동시에 써도 앱스 스크립트 실행 한도에 걸리지 않습니다.

## 설치 (선생님, 처음 한 번 · 10분)

```bash
npm install
npm run pack      # dist/appsscript/ 에 붙여 넣을 파일 4개가 생긴다
```

1. 구글 시트를 새로 만들고 **확장 프로그램 → Apps Script** 를 엽니다.
2. `Code.gs` 내용을 지우고 `dist/appsscript/Code.gs` 를 붙여 넣습니다.
3. **파일 + → HTML** 로 `index` 파일을 만들고 `dist/appsscript/index.html` 을 붙여 넣습니다.
4. ⚙️ 프로젝트 설정 → 「appsscript.json 매니페스트 파일 표시」 를 켜고 `appsscript.json` 을 붙여 넣습니다.
5. 저장 → 시트를 새로고침하면 메뉴 **🥤 부숴봐! 자판기** 가 생깁니다.
   **① 시트 준비하기 → ② 교사 암호 정하기** (처음 한 번 권한 승인).
6. **배포 → 새 배포 → 웹 앱** — 실행: **나**, 액세스: **모든 사용자**.
7. 나온 주소가 **학생 주소**, 끝에 `?page=teacher` 를 붙이면 **대시보드**입니다.

코드를 고친 뒤에는 **배포 관리 → ✏️ 수정 → 새 버전** 으로 바꿔야 주소가 그대로입니다.

시트는 네 장입니다 — `수업`(수업 목록) · `현황`(학생 한 명 = 한 줄: 학번·이름·자리·진행) · `기록`(사건 한 줄씩, 학번만) ·
`계정(비밀번호)`(숨김, 학번·이름·비밀번호 해시).
**비밀번호를 잊은 학생**은 시트 메뉴 **「③ 학생 비밀번호 초기화」** 에 학번을 적어 주세요. 활동 기록은 그대로 남고,
학생이 학번을 다시 적으면 이름을 확인한 뒤 새 비밀번호를 정합니다. 비밀번호를 10번 틀리면 그 학번은 10분 동안 막힙니다.
**학기가 끝나면 시트 메뉴 「기록 모두 지우기」 로 지워 주세요** (학생 계정까지 지웁니다).
⚠ 2026-10-25 에 `현황`·`기록` 열이 바뀌었습니다. 그 전에 만든 시트라면 두 탭을 지우고 「① 시트 준비하기」 를 다시 누르세요.

**한 반(30명 안팎)이 동시에 써도 됩니다.** 게임은 학생 컴퓨터 안에서 돌고, 시트에는 로그인·자리·찾은 예외·미션처럼
사건이 있을 때만 짧게 적습니다. 시트 쓰기는 한 번에 한 명씩이라 처음에 다 같이 로그인하면 뒷사람이 몇 초 기다리는데,
접속이 몰려 실패하면 화면이 「⏳ 친구들이 한꺼번에 들어오는 중이에요」 를 띄우고 **저절로 다시 시도**합니다.
게임 중에 보내지 못한 기록도 버리지 않고 조금 뒤 다시 보냅니다. 로그인을 분단별로 나눠 시키면 더 매끄럽습니다.

인터넷이 끊겼거나 서버 없이 쓰려면 `dist/index.html` 을 나눠 주세요. 더블클릭하면 「혼자 모드」로 게임이 그대로 됩니다.

## 개발

```bash
npm start              # 개발 서버 — 진짜 Code.gs 를 가짜 시트 위에서 돌린다 (교사 암호 teach1234)
npm test               # 시험 477가지 — 진짜 파이썬 대조 94사례 · 미션 채점 · 서버
npm run check:syntax   # 소스 전수 검사 (문법 · 저작권 · 화면 수명 · Code.gs)
npm run build          # dist/index.html 한 파일 (약 130KB)
npm run pack           # 위 + dist/appsscript/ (붙여 넣을 파일) + dist/gas-test.html
```

- 개발 서버를 켠 채 `학생 주소` 와 `?page=teacher` 를 탭 두 개로 열면, 같은 가짜 시트를 나눠 써서 배포 없이 처음부터 끝까지 시험할 수 있습니다.
- `dist/gas-test.html` — 묶은 파일에 `google.script.run` 대역을 붙인 판. 개발 서버에서 `/dist/gas-test.html` 로 열면 앱스 스크립트 안에서와 똑같이 돕니다.
- `PYTHONUTF8=1 python tools/golden.py` — 해석기를 견줄 기준을 진짜 파이썬으로 다시 만듭니다.
